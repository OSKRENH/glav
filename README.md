# Эталон — концепция нового сайта

Новая версия главной страницы Группы «Эталон» и пример страницы жилого проекта «Шагал».

## Что реализовано

- адаптивная главная с быстрым подбором проектов;
- карточки проектов с ценами, сроками и избранным;
- отдельная страница `/projects/shagal`;
- фильтр типов квартир;
- интерактивный ипотечный калькулятор;
- блоки хода строительства, инфраструктуры и способов покупки;
- фирменные цвета, логотипы и шрифт Gilroy.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm run install:ci
npm run dev
```

Проверка production-сборки:

```bash
npm test
```

## Стек

Vinext, React 19, TypeScript, Tailwind CSS и Radix UI.
